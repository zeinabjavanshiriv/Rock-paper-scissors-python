🪨 Rock Paper Scissors — Python

A simple command-line Rock Paper Scissors game built with Python.

🎮 About the Project

This project is a beginner Python game where the player competes against the computer in Rock Paper Scissors.

The project was created to practice Python programming fundamentals and build my first GitHub project.

✨ Features

- 🎮 Play against the computer
- 🔢 Choose the number of rounds
- 🎲 Random computer choices
- 🏆 Track wins, losses, and draws
- 🔄 Play again
- ❌ Handle invalid inputs
- 📋 Simple game menu

🧠 What I Practiced

- Variables
- "input()" and user interaction
- "if / elif / else"
- "while" loops
- "for" loops
- Functions
- Counters and statistics
- Random choices
- Basic game logic

🚀 How to Run

Make sure Python is installed on your computer.

Then run:

game.py
